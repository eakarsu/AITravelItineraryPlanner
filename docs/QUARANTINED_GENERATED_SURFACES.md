# Quarantined Generated Surfaces

The original application contains generated routes, direct chat completions, mock/sample behavior, broad public uploads, gap modules, default credentials, and a launcher that wrote configuration and reset state. The frontend still contains prototype pages for some of them. They are not supported product behavior.

The former `gapNoDeepIntegrationWithBookingPlatformsExpediaBooking.js` is superseded by the governed search, expiring quote, explicit approval, reservation outbox, provider receipt, and failure-recovery endpoints. Reintroducing a quarantined route requires consent-scoped authoritative inputs, tenant/subject state, non-consequential defaults, explicit failures, and acceptance tests equivalent to the governed API.
